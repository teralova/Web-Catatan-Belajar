Mengenal Git dan GitHub

Apa itu Git?

Git adalah sistem version control — alat untuk mencatat setiap perubahan pada kode secara bertahap, sehingga riwayat perubahan itu bisa dilihat, dibandingkan, atau dikembalikan kapan saja. Git berjalan di komputer sendiri, tanpa harus terhubung ke internet.

Dengan Git, beberapa orang bisa mengerjakan file yang sama tanpa saling menimpa pekerjaan satu sama lain. Setiap perubahan tersimpan sebagai satu titik dalam riwayat proyek, lengkap dengan siapa yang mengubah dan kapan.

Konsep dasar

Empat istilah ini muncul di hampir semua penjelasan Git. Memahami keempatnya sudah cukup untuk mulai bekerja.

  • Repository: tempat menyimpan semua file proyek dan riwayat perubahan
  • Commit: catatan tentang perubahan yang dibuat pada file proyek
  • Branch: cabang dari proyek utama untuk mengerjakan fitur baru atau perbaikan bug
  • Merge: menggabungkan perubahan dari satu branch ke branch lain

Perintah Dasar Git

Beberapa perintah/command dasar Git:

  • git init: Inisialisasi repository Git baru
  • git add: Menambahkan file ke staging area
  • git commit: Menyimpan perubahan ke repository
  • git push: Mengirim perubahan ke remote repository
  • git pull: Mengunduh perubahan dari remote repository

Apa itu GitHub?

GitHub adalah layanan hosting untuk proyek pengembangan perangkat lunak yang menggunakan sistem kontrol versi Git. Jika Git bekerja secara lokal di komputer, GitHub menyediakan tempat menyimpan repo itu secara daring agar bisa diakses, dibagikan, dan dikerjakan bersama tim dari mana saja.

Selain penyimpanan, GitHub menambahkan fitur kolaborasi seperti issue untuk mencatat tugas atau bug, pull request untuk meninjau perubahan sebelum digabungkan, dan halaman proyek untuk dokumentasi.

Alur kerja umum

Begini urutan kerja yang biasa dipakai saat menggunakan Git bersama GitHub dalam sebuah proyek.

  1. Clone repository >>> Menyalin repository dari GitHub ke komputer dengan git clone, agar bisa dikerjakan secara lokal
  2. Buat branch baru >>> Memisahkan pekerjaan dari kode utama dengan git branch dan git checkout, supaya perubahan tidak langsung memengaruhi branch utama.
  3. Commit perubahan >>> Menyimpan progres secara bertahap dengan git add dan git commit, masing-masing disertai pesan yang jelas.
  4. Push ke GitHub >>> Mengirim commit dari komputer ke repo GitHub dengan git push, sehingga tersimpan dan bisa dilihat tim.
  5. Ajukan pull request >>>Meminta perubahan pada branch ditinjau dan digabungkan ke branch utama lewat pull request di GitHub.

Bedanya Git dan GitHub

Git adalah sistem version control yang digunakan untuk melacak perubahan dalam file-file proyek, sedangkan Github adalah platform hosting untuk proyek Git.

Kenapa perlu dipelajari

  • Riwayat perubahan kode tercatat rapi dan bisa dikembalikan jika terjadi kesalahan.
  • Beberapa orang bisa mengerjakan proyek yang sama tanpa saling menimpa pekerjaan.
  • Fitur branch memungkinkan eksperimen tanpa mengganggu kode yang sudah stabil.
  • Hampir semua proyek open source dan perusahaan software menggunakan Git & GitHub sebagai standar kerja.
