Learn How the Web is Built

1. What is HTML?

HTML adalah singkatan dari Hypertext Markup Language. Jika diambil pengertian dari masing-masing istilah tersebut, maka Hypertext merupakan dokumen yang berisi tautan (link), yang memungkinkan pengguna terhubung ke halaman yang lain. Sedangkan Markup Language merupakan sekumpulan code yang dipahami oleh komputer, yang nantinya menghasilkan suatu informasi. Dengan demikian, bila pengertian dari kedua istilah tersebut digabungkan, maka HTML adalah bahasa markup/markup languange yang digunakan untuk membuat struktur halaman website.

2. Basic HTML Structure

Setiap Dokumen HTML memiliki basic structure. Berikut adalah contoh-contohnya: 

<!DOCTYPE html>
<html>
<head>
<title>My First Website</title>
</head>
<body>
<h1>Hello World!</h1>
<p>This is my first website.</p>
</body>
</html>

3. Tags & Elements

Elemen HTML adalah satu kesatuan utuh yang mencakup tag pembuka, konten di bagian tengah, dan tag penutup. Sementara itu, tag HTML hanyalah potongan kode yang diapit oleh tanda kurung sudut < > yang memberi tahu peramban cara menafsirkan konten tersebut.

Contoh:

<h1>Hello World!</h1>
<p>This is a paragraph.</p>
<a href="#">Visit Website</a>

4. Links & Images

Links

link (tautan) dan image (gambar) dalam HTML adalah elemen dasar untuk membuat halaman web menjadi interaktif dan kaya visual

1. Link (Tautan / Hyperlink)

Pengertian: Elemen HTML yang berfungsi untuk menghubungkan satu halaman web ke halaman web lainnya, baik di dalam situs yang sama maupun ke situs luar (eksternal).

Tag utama: Menggunakan tag <a> (anchor). Atribut penting: href (Hypertext Reference) untuk menentukan URL atau alamat tujuan yang akan dikunjungi saat link diklik.

2. Image (Gambar)

Pengertian: Elemen HTML yang digunakan untuk menyisipkan atau menampilkan file gambar (seperti JPG, PNG, atau GIF) ke dalam halaman web.

Tag utama: Menggunakan tag <img>. Tag ini tidak memerlukan tag penutup.

Atribut penting:

  • src (Source): Menentukan lokasi atau jalur (path) file gambar.
  • alt (Alternative text): Teks pengganti yang muncul jika gambar gagal dimuat oleh browser.
  • width dan height: Mengatur ukuran lebar dan tinggi gambar.
<a href="https://example.com">
Visit Website
</a>

Images

The <img> tag is used to display images on a webpage. 

<img src="image.jpg" alt="Example Image">

5. Attributes

informasi atau nilai tambahan yang diletakkan di dalam tag pembuka untuk mengatur perilaku, tampilan, atau fungsi dari suatu elemen

  • Nama Atribut: Menunjukkan properti yang ingin diatur (contoh: src, href, class).
  • Value: Informasi spesifik dari atribut yang biasanya diapit oleh tanda petik.
  • Contoh Penulisan: Tautan di mana href adalah atribut dan URL-nya adalah nilai.

Example:

<p class="highlight">
    Hello World!
</p>

beberapa atribut HTML:

  • class
  • id
  • href
  • src
  • alt
